## Changes published

- Each public route now serves its own HTML title, description, canonical and sharing metadata before JavaScript executes. Client navigation keeps those values in sync.
- Sitemap contains homepage, privacy and terms with accurate modification dates. Login is noindex and excluded from the sitemap; private workspace routes retain their existing robots restrictions.
- Workspace/admin pages and their layouts load on demand. Public dependencies preload from the Vite build manifest without preloading private pages.
- Four artwork images use verified WebP variants: 6,067,887 bytes of PNG originals reduced to 239,244 bytes. Original PNGs are retained.
- Dashboard video loads near the viewport, with a lightweight poster and the same automatic playback.
- Lordicon script no longer blocks HTML parsing. Hero text appears immediately; footer heading levels are corrected.
- Anonymous visitors no longer fetch workspace feature flags or open the feature-flags Realtime channel. Signed-in subscriptions remain enabled and cleaned up.

## Search Console observations and actions

- Verified owner of the domain property `boostd.app`.
- Sitemap submission accepted. Reindexing requests accepted for homepage, privacy and terms. Acceptance is a crawl request, not confirmation that legal pages are already indexed.
- Homepage was already indexed. Before this change, privacy, terms and login were discovered but not indexed. The other reported exclusions were redirects and an old HTTP URL; those are not pages to force into the index.
- No manual actions or security issues reported. HTTPS report: one HTTPS URL, zero non-HTTPS URLs, no issues in the previous 90 days.
- Core Web Vitals has insufficient real-user usage data for both device types.
- Search performance for the selected three-month range: 2 clicks, 203 impressions, 1% CTR, average position 30.1. These historical metrics cannot be changed immediately through settings.
